# Automatic-File-Sorter

A Python automation tool that organizes files based on their extensions. It scans a selected directory, automatically creates folders for different file types, and moves files into the appropriate folders, making file management simple and efficient.

## ✨ Features
- Automatically sorts files by their extensions.
- Creates folders if they do not exist.
- Supports documents, images, videos, audio, archives, and other file types.
- Reduces manual effort in organizing files.

## 🛠️ Technologies Used
- Python
- os
- shutil
- pathlib

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Update the directory path in the script if needed.
4. Run the script:

```bash
python files_sorting.py
```
